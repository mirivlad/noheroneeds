# No Hero Needed — «Герой не требуется»

Долговременная 2D-пиксельная песочница на Godot 4.7: живой мир, в котором можно поселиться, строить, торговать, исследовать — или просто жить.

- Дизайн: [docs/design/](docs/design/README.md) — GDD, архитектурные ориентиры, открытые вопросы.
- Принятые решения: [docs/adr/](docs/adr/README.md). Предложения на обсуждении: [docs/proposals/](docs/proposals/).

## Запуск

```bash
tools/fetch_addons.sh   # один раз: нативные расширения (SQLite), не хранятся в git
tools/run_tests.sh      # headless-тесты; --bench добавляет медленные замеры
```

Игра (одиночная — через локальный сервер в том же процессе):

```bash
godot --path .
```

Подключение к выделенному серверу: `godot --path . -- --connect=адрес:порт`. Управление пока временное: WASD — ходить, 1–3 — выбрать деталь, ЛКМ — построить, ПКМ — разобрать.

Выделенный сервер:

```bash
tools/run_server.sh --world=/путь/к/world.db --port=24680
```

Остановка — команда `stop` в его консоли или файл `STOP` рядом с базой мира.

Нужен Godot 4.7.2 (`godot` в PATH или переменная `GODOT`).

Известное: при самом первом импорте проекта (пустой `.godot/`) Godot 4.7.2 аварийно завершается при выходе после загрузки расширения SQLite; импорт при этом выполнен, повторный запуск работает.
