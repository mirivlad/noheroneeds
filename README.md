# No Hero Needed — «Герой не требуется»

Долговременная 2D-пиксельная песочница на Godot 4.7: живой мир, в котором можно поселиться, строить, торговать, исследовать — или просто жить.

- Дизайн: [docs/design/](docs/design/README.md) — GDD, архитектурные ориентиры, открытые вопросы.
- Принятые решения: [docs/adr/](docs/adr/README.md). Предложения на обсуждении: [docs/proposals/](docs/proposals/).

## Запуск

```bash
tools/fetch_addons.sh   # один раз: нативные расширения (SQLite), не хранятся в git
tools/run_tests.sh      # headless-тесты; --bench добавляет медленные замеры
```

Игра (одиночная — через локальный сервер в том же процессе):

```bash
tools/run_game.sh
```

Скрипт сначала импортирует новые картинки и скрипты: после `git pull` это обязательно. Голый `godot --path .` сам ничего не импортирует, это делает только редактор.

Экран — **960×540** (на 1920×1080 — ×2). Вся графика — пиксель-арт из открытых наборов
Liberated Pixel Cup: [художественный стандарт](docs/art/ART_STANDARD.md), авторы —
[CREDITS-art.md](CREDITS-art.md) и «Авторы» в меню. Исходники наборов в git не хранятся:

```bash
tools/art/fetch_lpc.sh && tools/art/fetch_lpc_env.sh   # один раз, для пересборки графики
python3 tools/art/import_lpc.py && python3 tools/art/import_lpc_env.py && python3 tools/art/import_lpc_animals.py
```

Игра открывается меню:
- новая игра — локально или как свой сервер, с правилами мира;
- загрузка сохранённых миров;
- подключение к серверу;
- персонажи: создание и редактор внешности (пол, лицо, причёска, кожа, цвет волос и глаз); внешность меняется после выхода из мира;
- авторы: кто нарисовал людей, мир и зверей (наборы LPC, [CREDITS-art.md](CREDITS-art.md)).
- настройки.

В игре Esc открывает меню. Сразу подключиться к серверу без меню: `tools/run_game.sh --connect=адрес:порт`. Управление (ADR-0021): WASD — ходить (с Ctrl — бег). Действие зависит от того, что в руках, и от того, на что указывает курсор: ЛКМ — главное (ударить, выстрелить, копать киркой, рубить топором, осмотреть; держать — продолжать: дерево рубится несколько ударов), ПКМ — меню всех действий, E — быстрое (открыть дверь или сундук, подобрать, подняться, спуститься, спрыгнуть в соседний проём). 1–9 или колесо — что взять в руки, C — персонаж и экипировка (надеть — из инвентаря, снять — нажать на слот), I — вещи: сумка из 36 ячеек, стопка в ячейке (двойной щелчок — надеть или взять в руки; перетаскивание — в другую ячейку, на панель внизу или на куклу; ПКМ — бросить: Shift — стопку, Ctrl — половину; что не влезло в полную сумку, падает под ноги), Q — выхватить оружие и обратно, G — бросить одно из того, что в руках. K — ремёсла (у верстака, печи или костра; еду в руках ЛКМ — съесть). Сытость (вверху экрана) убывает со временем и работой: голодный не лечится, а совсем пустой понемногу теряет здоровье. Бодрость тратится за день-два: уставший не может бежать, выспаться можно в кровати (E — «Лечь спать», проснуться — шагнуть). Ночью и в дождь под открытым небом холодно: спасают одежда (шерстяной плащ шьют из ткани), крыша и костёр. Ведро (верстак) набирает воду у пруда и молоко у своей коровы: водой поливают грядки, молоко пьют, лишнее выливают. Рядом с началом стоит деревня: её жители работают каждый своим ремеслом (поле, кузница, рыбалка, загон), вечером собираются у костра, ночью спят дома и заговаривают с теми, кто подходит. С жителями говорят (E на жителе): у каждого есть имя, у деревни — название и летопись (прошлое и то, что случилось при вас: волки у деревни, приход осени, нападения, ваши поступки). Из летописи вырастают просьбы: найти оберег, потерянный в настоящей пещере, отвадить хищников, принести дров к зиме или руды в кузницу — за монеты. L — журнал взятого и летописей. Обиженный житель день не говорит и не торгует с обидчиком. С жителями торгуют за монеты (кнопка «Торговать» или ПКМ): у каждого ремесла свои товары и закупки, запас и кошелёк обновляются с утра. Год — четыре сезона по неделе: зимой холодно, идёт снег, и поля не растут. Погода (в строке времени) меняется сама: дождь поливает поля и прячет вас от зверей, утром бывает туман. Мотыгой ЛКМ по траве — вспахать, семенами по пашне — посеять, спелое — собрать. Удочкой ЛКМ по воде — ловить рыбу (держать — забрасывать снова): клюёт не всегда, лучше на рассвете и закате, а выловленное место надо оставить на время; рыбу жарят на костре. Шкуры выделываются в кожу, из кожи — доспех; доспех и шлем снимают часть каждого удара (защита видна в окне персонажа). Овцу, корову или курицу приручают, кормя их едой из рук (ЛКМ): своё животное идёт за тем, кто держит его еду, и остаётся там, куда привели, — например, в загоне; сытые дают шерсть, яйца и приплод. B — каталог строительства: выбранный чертёж ставится ЛКМ (протянуть — ряд или площадь), R — повернуть, ПКМ — отпустить; там же «Разобрать своё». Чужое не разбирают, а ломают ударами, и камень ломается долго (ADR-0016). В меню своей двери есть «Поставить замок» (код из 4 цифр), в меню другого игрока — «Добавить в друзья»: друзья открывают ваши сундуки и запертые двери. J — спрыгнуть с края или в проём (или «Спрыгнуть вниз» в меню на пустоте), F — лестница или ход между глубинами (Shift+F — вниз), M — карта мира, − и = — миникарта, Esc — меню.

Выделенный сервер:

```bash
tools/run_server.sh --world=/путь/к/world.db --port=24680
```

Остановка — команда `stop` в его консоли или файл `STOP` рядом с базой мира.

## Сборка для игроков

```bash
tools/export.sh
```

Собирает Linux (`build/linux/noheroneeds.x86_64`) и Windows (`build/windows/noheroneeds.exe`), рядом с каждым — библиотека SQLite, и архивы `build/noheroneeds-<версия>-<коммит>-linux-x86_64.tar.gz` и `…-windows-x86_64.zip`. Только одна платформа: `tools/export.sh linux` или `tools/export.sh windows`; отладочная сборка: `--debug`. Нужны шаблоны экспорта Godot той же версии (4.7.2).

### Релизы

```
tools/package.sh 0.2.0
```

Собирает в `build/release/` всё для выпуска, с иконкой игры (`assets/icon`, делает её `tools/art/make_icon.py`):
- `noheroneeds-<версия>-linux-x86_64.tar.gz` — бинарник для Linux;
- `noheroneeds-<версия>-windows-portable.zip` — exe для Windows без установки;
- `noheroneeds-<версия>-windows-setup.exe` — установщик для Windows: «Пуск», рабочий стол, удаление через «Приложения» (нужен `makensis`, пакет `nsis`);
- `noheroneeds_<версия>_amd64.deb` — для Debian и Ubuntu: игра в `/opt/noheroneeds`, запуск командой `noheroneeds`, пункт в меню и иконки;
- `SHA256SUMS`.

На GitHub это делает сам: тег `vX.Y.Z` (`git tag v0.2.0 && git push origin v0.2.0`) запускает `.github/workflows/release.yml` — тесты, сборку и релиз с этими файлами. Вручную: Actions → release → Run workflow с версией (выйдет черновик релиза).

Собранная игра — она же выделенный сервер:

```bash
./noheroneeds.x86_64 --headless -- --server --world=/путь/к/world.db --port=24680
```

(в Windows — `noheroneeds.exe --headless -- --server …`; параметры те же, что у `tools/run_server.sh`).

Нужен Godot 4.7.2 (`godot` в PATH или переменная `GODOT`).

`tools/fetch_addons.sh` также заранее регистрирует расширение в `.godot/`: без этого самый первый импорт в Godot 4.7.2 падает на выходе (сам импорт при этом завершается).
