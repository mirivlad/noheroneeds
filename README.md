# No Hero Needed — «Герой не требуется»

Долговременная 2D-пиксельная песочница на Godot 4.x: живой мир, в котором можно поселиться, строить, торговать, исследовать — или просто жить.

- Дизайн: [docs/design/](docs/design/README.md) — GDD, архитектурные ориентиры, открытые вопросы.
- Предложения на согласовании: [docs/proposals/](docs/proposals/).
