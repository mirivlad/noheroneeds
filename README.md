# No Hero Needed — «Герой не требуется»

Долговременная 2D-пиксельная песочница на Godot 4.7: живой мир, в котором можно поселиться, строить, торговать, исследовать — или просто жить.

- Дизайн: [docs/design/](docs/design/README.md) — GDD, архитектурные ориентиры, открытые вопросы.
- Принятые решения: [docs/adr/](docs/adr/README.md). Предложения на обсуждении: [docs/proposals/](docs/proposals/).

## Запуск

```bash
tools/fetch_addons.sh   # один раз: нативные расширения (SQLite), не хранятся в git
tools/run_tests.sh      # headless-тесты; --bench добавляет медленные замеры
```

Игра (одиночная — через локальный сервер в том же процессе):

```bash
tools/run_game.sh
```

Скрипт сначала импортирует новые картинки и скрипты: после `git pull` это обязательно. Голый `godot --path .` сам ничего не импортирует, это делает только редактор.

Игра открывается меню:
- новая игра — локально или как свой сервер, с правилами мира;
- загрузка сохранённых миров;
- подключение к серверу;
- персонажи;
- настройки.

В игре Esc открывает меню. Сразу подключиться к серверу без меню: `tools/run_game.sh --connect=адрес:порт`. Управление (ADR-0021): WASD — ходить (с Ctrl — бег). Действие зависит от того, что в руках, и от того, на что указывает курсор: ЛКМ — главное (ударить, выстрелить, копать киркой, рубить топором, осмотреть), ПКМ — меню всех действий, E — быстрое (открыть дверь или сундук, подобрать, подняться, спуститься, спрыгнуть в соседний проём). 1–9 или колесо — что взять в руки, I — вещи (щелчок или перетаскивание — в ячейку, ПКМ — бросить: Shift — всё, Ctrl — половину), Q — выхватить оружие и обратно, G — бросить одно из того, что в руках. B — каталог строительства: выбранный чертёж ставится ЛКМ (протянуть — ряд или площадь), R — повернуть, ПКМ — отпустить; там же «Разобрать своё». Чужое не разбирают, а ломают ударами, и камень ломается долго (ADR-0016). В меню своей двери есть «Поставить замок» (код из 4 цифр), в меню другого игрока — «Добавить в друзья»: друзья открывают ваши сундуки и запертые двери. J — спрыгнуть с края или в проём (или «Спрыгнуть вниз» в меню на пустоте), F — лестница или ход между глубинами (Shift+F — вниз), M — карта мира, − и = — миникарта, Esc — меню.

Выделенный сервер:

```bash
tools/run_server.sh --world=/путь/к/world.db --port=24680
```

Остановка — команда `stop` в его консоли или файл `STOP` рядом с базой мира.

## Сборка для игроков

```bash
tools/export.sh
```

Собирает Linux (`build/linux/noheroneeds.x86_64`) и Windows (`build/windows/noheroneeds.exe`), рядом с каждым — библиотека SQLite, и архивы `build/noheroneeds-<версия>-<коммит>-linux-x86_64.tar.gz` и `…-windows-x86_64.zip`. Только одна платформа: `tools/export.sh linux` или `tools/export.sh windows`; отладочная сборка: `--debug`. Нужны шаблоны экспорта Godot той же версии (4.7.2).

Собранная игра — она же выделенный сервер:

```bash
./noheroneeds.x86_64 --headless -- --server --world=/путь/к/world.db --port=24680
```

(в Windows — `noheroneeds.exe --headless -- --server …`; параметры те же, что у `tools/run_server.sh`).

Нужен Godot 4.7.2 (`godot` в PATH или переменная `GODOT`).

`tools/fetch_addons.sh` также заранее регистрирует расширение в `.godot/`: без этого самый первый импорт в Godot 4.7.2 падает на выходе (сам импорт при этом завершается).
