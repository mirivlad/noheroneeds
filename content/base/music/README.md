# Музыка базового пакета

Треки автора раскладываются по папкам настроений: `explore/`, `forest/`, `home/`, позже `night/` и `danger/`. Форматы — ogg (лучше всего), mp3 или wav. Игра находит файлы сама, править ничего не нужно (`src/presentation/music_director.gd`).

| Папка | Когда звучит |
|---|---|
| `explore` | открытая местность днём; запасное настроение для всех остальных |
| `forest` | игрок среди деревьев (больше половины земли вокруг — лес) |
| `home` | игрок под крышей, в своём доме |
| `night` | ночь (когда появится смена дня и ночи) |
| `danger` | опасность, бой (шаг 10) |

Треки одного настроения идут по очереди с тишиной 40–150 с между ними. Смена настроения — затухание за 4 с и вступление нового трека за 3 с. Настроение должно продержаться 8 с, прежде чем музыка за ним последует.
