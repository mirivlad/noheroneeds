# ADR-0002 — Движок, язык и симуляция вне дерева сцен

**Статус:** принято автором 14.10.2026.

## Решение

1. **Godot 4.7.2** (stable). Обновления движка — отдельными изменениями с прогоном всех тестов.
2. **GDScript со статической типизацией.** Горячие места при доказанной необходимости выносятся в GDExtension.
3. **Игровая симуляция — обычные объекты, вне дерева сцен.** Она работает только на сервере, по явным тикам и без зависимости от частоты кадров. Сцены Godot (`presentation/`) лишь показывают зеркало состояния на клиенте и не решают исход действий.

## Почему

- Симуляция headless тестируется без сцен. Сервер ничего не рисует. Множество локаций (поверхность, этажи, пещеры) не требует отдельного физического мира Godot на каждую.
- Утилитарные классы Godot без дерева сцен — `AStarGrid2D`, `FastNoiseLite`, `RandomNumberGenerator`, `Crypto` — доступны симуляции.

## Последствия

- Столкновения, поиск пути и видимость считаются по сеткам и формам симуляции, а не физикой Godot.
- Одиночная игра — тот же `GameServer` в процессе клиента.
- Сеть и хранилище — `docs/proposals/002-network-storage-identity.md` (на обсуждении).
