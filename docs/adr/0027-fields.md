# ADR-0027 — Земледелие, первая очередь: пашня, посев, рост, урожай

**Статус:** принято 20.10.2026, реализовано.

## Решение

1. **Пашня — грунт.** Грунт с `tilled` вспахивается в указанный (трава, земля, мох,
   лесная подстилка → `base:farmland`) орудием вида `tilling` в руках (мотыга),
   если на клетке ничего не растёт и не стоит. Запрос `till`.
2. **Посев.** Вещь с `plants` (семена) сажает свой посев на пашню (`farmland`):
   посев занимает слой растений клетки, время посева — в его свойствах (`planted`,
   мс мира). Запрос `sow`.
3. **Рост — по часам мира.** Посев (`crop: {stages, grow_hours}`) проходит стадии
   равномерно до спелости через `grow_hours` игровых часов (`Crops.stage`). Сервер и
   клиенты считают стадию сами по одному времени мира: пока посев растёт, по сети
   ничего не идёт; клиент раз в секунду обновляет картинки посевов.
4. **Урожай** — сбор (`gather`) руками, только спелого (`not_ripe` иначе): дроп —
   плоды и семена; пашня остаётся.
5. **Начало цепочки:** семена пшеницы — с высокой травы, моркови — с клевера;
   пшеница → хлеб (печь), морковь — еда сырой. Картинки — [LPC] Farming (Daniel Eddeland).

## Последствия

- Новая культура — данные: семена, посев со стадиями, картинки стадий.
- Полив, сезоны, вредители, удобрения и урожайность от навыка — следующие очереди.
