# ADR-0059 — Причёски RO: любой цвет и срез под головным убором

**Статус:** принято 27.10.2026 по решению автора.

## Решение

1. **Причёски берутся с моделей VRoid под CC0** (pixiv: HairSample_Male и
   HairSample_Female, Sendagaya Shibu, Sendagaya Shino, Sakurada Fumiriya,
   Victoria Rubin, Vita, Vivi). Сетка волос подгоняется к нашей голове по коже
   головы (ширина и глубина, макушка на макушку) и висит на тех же костях
   (`build_hair.py`). Каждая причёска есть у обоих тел RO
   (`base:ro_hair_<стиль>`). AvatarSample A–C не берутся: их условия
   запрещают переносить данные в сервисы создания персонажей.
2. **Волосы рендерятся оттенками серого, цвет задаёт игра.** Средний серый
   становится выбранным цветом, тёмные — его тенями, светлые — бликами к
   белому. Цвет — любой: в редакторе для тел RO вместо списка цветовой круг.
3. **Под головным убором волосы срезаются по «запретному объёму» убора, а не
   отдельными спрайтами причёска×убор.** Объём — вертикальный цилиндр вокруг
   головы выше края убора. Он снимается для каждого кадра только в глубину:
   ближняя и дальняя сторона. Пиксель волос, глубина которого лежит между
   ними, внутри объёма и не рисуется. Глубина пикселя волос хранится в его
   атласе (серый — в красном канале, байт глубины — в зелёном), глубины
   объёма — в атласе убора.
4. Все шапки одинаково облегают все причёски: оболочка строится по самой
   объёмной из них, не больше `HAIR_ROOM` над черепом.

## Последствия

- Число спрайтов растёт линейно: каждая новая причёска и каждый новый убор
  снимаются один раз. Пар «причёска под убором» не существует.
- Срез честный по глубине: пряди ниже края убора остаются, даже если на
  экране они рядом с объёмом.
- Атлас причёски — не картинка: смотреть его можно только через
  `compose.py` или игру.
- Байт глубины покрывает 2,2 м вокруг головы, около 9 мм на шаг: этого хватает
  для среза с точностью до пикселя.
