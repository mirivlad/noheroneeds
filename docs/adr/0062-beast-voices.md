# ADR-0062 — Голоса зверей по событиям

**Статус:** принято 28.10.2026 по замечанию автора (27.10.2026): звери не должны
звучать часто. Дополняет ADR-0037 («нет голосов зверей»).

## Решение

1. **Звук — данные** (`content/base/voices.json`, как `sounds.json`): у зверя
   события `voice` (сам по себе, раз в `every: [меньше, больше]` секунд, у
   каждого свой срок; первый — не раньше половины меньшего, чтобы стадо не
   голосило хором), `attack` (его удар), `chase` (начал охоту на кого-то) и
   `death` (погиб).
2. **Как сейчас:** корова, овца, курица, олень и лиса изредка подают голос;
   волк молчит, рычит при ударе и один раз воет, начиная погоню; медведь рычит;
   все кричат, погибая (заяц и крыса — писком).
3. **Откуда клиент знает:** удар — по счётчику ударов существа (как удары
   людей); охота — по признаку `hunting` у тех, кто бьёт (меняется только при
   переходе); гибель — по списку `died` в снимке: существо исчезает в тот же
   такт, и иначе его не отличить от ушедшего. Протокол — версия 13.
4. **Записи свободные** (CC0, CC-BY, CC-BY-SA, общественное достояние) с
   OpenGameArt и Wikimedia Commons, вырезаны по паузам и выровнены по
   громкости `tools/audio/import_animal_voices.py`; авторы — в
   `CREDITS-audio.md`.

## Последствия

- Записи выбраны автоматически, без прослушивания: их стоит послушать и при
  нужде заменить другими кусками.
