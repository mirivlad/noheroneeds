# Журнал архитектурных решений

Принятые решения, затрагивающие несколько подсистем или необратимость данных. Предложения на обсуждении — в `docs/proposals/`; после согласования решение попадает сюда и в `docs/design/GDD.md`, а соответствующий вопрос удаляется из `docs/design/OPEN_QUESTIONS.md`.

| ADR | Решение | Статус |
|---|---|---|
| [0001](0001-art-scale-and-character-layers.md) | Тайл 16, 8 направлений, слоистые кадры; пересмотр: гуманоид 18×32 (A1), контур по ролям, база B4, средняя палитра | Принято, пересмотрено |
| [0002](0002-engine-language-simulation.md) | Godot 4.7.2, GDScript, симуляция вне дерева сцен | Принято |
| [0003](0003-player-identity.md) | Идентичность: UUID персонажа + криптографический ключ игрока | Принято |
| [0004](0004-network.md) | Сеть: MultiplayerAPI + ENet как транспорт, свои сообщения, версия протокола, каналы | Принято |
| [0005](0005-world-storage.md) | Хранилище: SQLite + бинарные чанки с палитрой, CBOR, миграции, испытание | Принято |
| [0006](0006-signatures-and-portable-profile.md) | RSA-3072, ID алгоритма и версии форматов, подпись владельца ≠ заверение сервера | Принято |
| [0007](0007-building-levels.md) | Перекрытия, этажи, крыши без строительной физики; этажность — настройка сервера | Принято, реализовано (первая очередь) |
| [0008](0008-art-pipeline.md) | Художественный стандарт; генерация — материалы и образы, точность — инструмент импорта; персонажи на шаблоне тела | Принято |
| [0009](0009-rules-and-visuals-compatibility.md) | Совместимость правил отдельно от графики и текстов; текстурпаки | Принято, реализовано |
| [0010](0010-paper-doll-in-game.md) | Бумажная кукла в игре: слои по `visual`, анимации из шаблона тела, стартовая одежда — правило мира | Принято, реализовано (первая очередь) |
| [0011](0011-menu-worlds-hosting.md) | Меню игры; миры с правилами в `world.json`; персонажи; свой сервер из игры через обычный клиент | Принято, реализовано |
| [0012](0012-sound.md) | Звук: определения `sound` в контенте, синтез эффектов, события из разницы чанков, музыка автора по настроению | Принято, реализовано |
| [0013](0013-rotation.md) | Поворот деталей (rotations, facing, R); лестница выводит над собой или туда, куда смотрит её верх | Принято, реализовано (механика, лестница) |
| [0014](0014-world-time-and-light.md) | Время мира на сервере, сохраняется и синхронизируется; длина суток — правило мира; день и ночь; освещённость клетки и источники света | Принято, реализовано |
| [0015](0015-openings-and-outdoor-positions.md) | Окна и бойницы с секторами из данных; обзор и стрельба у проёма с проверкой сервером; наружные позиции; скатная кровля непроходима; без 3D-баллистики (Q-06) | Принято, обзор реализован; стрельба — с боем |
| [0016](0016-pvp-and-permissions.md) | PvE основной; PvP — настройка сервера; права на чужое — отдельная система разрешений; набеги и разрушения — отдельные настройки (Q-07) | Принято |
| [0017](0017-persistent-dungeons.md) | Подземный мир: общая геология X/Y/Z по чанкам, сохраняется навсегда; свободные горизонтальные раскопки; переходы между уровнями игрок создаёт сам; вход с поверхности — особое сооружение; месторождения — свойство генерации; без Z-слоёв на экране (Q-08) | Принято, реализовано (первая очередь) |
| [0018](0018-creatures.md) | Живые существа на сервере: данные контента, честное восприятие (зрение со светом и заслонением, слух), память, уровни активности, бюджет раздумий, заселение по биомам | Принято, реализовано (первая очередь) |
| [0019](0019-combat.md) | Бой: здоровье, оружие из данных (ближнее, дальнее), удар — запрос с проверкой досягаемости, сектора и видимости; стрела — снаряд по плану; PvP и потеря вещей при смерти — правила мира; волк | Принято (по умолчанию), реализовано (первая очередь) |
| [0020](0020-maps-and-modes.md) | Карта разведанного хранится за персонажем на сервере; миникарта (1–4 экрана) и карта мира по уровням; (режимы мыши заменены ADR-0021) | Принято, реализовано |
| [0021](0021-interaction.md) | Действие — от предмета в руках и цели (данные контента); ПКМ — меню действий; панель предметов игрока; строительство — каталог чертежей (B), разборка — отдельный инструмент; добыча `gather` | Принято, реализовано |
