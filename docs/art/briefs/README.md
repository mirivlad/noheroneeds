# Брифы для генерации

Как работаем (ADR-0008):

1. **Беру бриф** из этого каталога и генерирую по нему в ChatGPT. К каждому запросу прикладываю как образец стиля `docs/proposals/001-foundation/art/probe_B2_colored_1080p.png`.
2. **Выбираю подходящие картинки** и кладу их как есть в `art_src/incoming/<номер брифа>/` с именами из брифа. Каталог `art_src/` не в git. Если вариантов несколько, добавляю к имени `_a`, `_b`.
3. **Пишу Claude:** «бриф NNN готов». Он обрабатывает картинки (размер, палитра, контур, переходы, раскладка), подключает их к игре и показывает снимок.
4. **Если результат не нравится,** правим запрос в брифе и повторяем. Удачные запросы остаются в брифе как основа для следующих ассетов.

## Общие правила запросов

- **Объекты — по одному на картинку** на ровном фоне **#FF00FF** (чистая маджента). Фон инструмент вырезает.
- **Фактуры — во весь кадр, бесшовные,** без объектов.
- **Без контура и без тени на земле:** контур и тени добавляет инструмент и движок, одинаково для всех ассетов.
- **«Крупные пиксели»:** просим, чтобы картинка выглядела как маленький спрайт, увеличенный в 16 раз, — каждый пиксель спрайта ровным квадратом. Генерация не делает это идеально, инструмент выравнивает. Но чем ровнее квадраты, тем лучше результат.
- **Свет сверху-слева,** палитра ограничена, без градиентов внутри пикселя, без размытия.
