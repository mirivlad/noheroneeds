# No Hero Needed — пакет GDD 0.2 для Claude

**Дата:** 14 октября 2026  
**Роль:** живая проектная документация для разработки 2D-пиксельной песочницы.

## С чего начать

1. **`GDD.md`** — главный документ; концепция, уже принятые решения, игровые системы, сценарии и задачи.
2. **`ARCHITECTURE.md`** — предложения о доменных границах, сохранениях, сетевой модели, переносимом персонаже. Не считать все имена классов утверждёнными.
3. **`DEVELOPMENT.md`** — философия длительной разработки без MVP и инженерная дисциплина.
4. **`OPEN_QUESTIONS.md`** — решения, которые Claude не должен принимать за автора.
5. **`REFERENCES.md`** — художественные, механические и технические референсы.
6. **`assets/`** — авторские схемы и палитра из прежнего GDD, не игровые спрайты.

## Критические установки

- Исходная 3D-версия удалена пользователем. **Проектировать с нуля только 2D**, не предлагать аудит/портирование прежней 3D-архитектуры.
- **Не MVP.** Игра не проектируется ради быстрого релиза, инвестора, коммерческих KPI или заранее установленной точки «готово». Цель — расширять мир годами, как Dwarf Fortress/NetHack, сохраняя в каждой версии играбельность, качество и целостность.
- Мультиплеер и выделенный сервер — фундамент. Чиби-редактор персонажа и переносимый полный профиль между совместимыми серверами — фундамент. Точная семантика переезда/копий пока не выбрана.
- Не менять «один бесшовный Z=0 + отдельные верхние этажи/пещеры + наружные крыши и стрельба между высотами» на свободную 3D-геометрию или Dwarf Fortress Z-слои.
- Просить решение автора по открытым вопросам, вместо тихого закрепления спорных допущений.

## Быстрый промпт для Claude

Скопировать содержимое `CLAUDE_BRIEF.md` в задачу Claude, приложить весь этот каталог в репозиторий (например, `docs/design/`) и попросить начать с анализа документов и предложения архитектуры **нового** Godot-проекта, а не с массового написания исходников.

## Изменения относительно GDD 0.1

- Убран аудит/перенос старой 3D-версии; это новый 2D-проект.
- Убрана философия MVP/быстрого релиза; добавлен принцип бессрочного эволюционного развития.
- Усилен системный подход к взаимодействию механик и защита долгоживущих сохранений.
- Обязательны редактор персонажа, портативная внешность/навыки/инвентарь и архитектура межсерверного переноса.
- Явно разделены переносимый персонаж, состояние персонажа в мире и мировая собственность.
- Сохранены конструкции, крыши, осады, подземелья и художественная концепция; нерешённые вопросы вынесены отдельно.
