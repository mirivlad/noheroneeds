Измерения последовательные, без фоновых тестов/другого игрового окна,
120 кадров прогрева / 360 измерений, VSync/лимит отключены. p95 шести сцен

снега (4 → 3). Это локальное время целого кадра, не GPU-таймер или гарантия
подгрузки/памяти. Цифры и границы — [ATMOSPHERE_REPORT](../../ATMOSPHERE_REPORT.md).

Первый замер с новым движением солнца [отклонён](rejected-moving-sun.json):
берег +15,6%. Исследование только направления света:
[основа](shore-study-before.json) / [кандидат](shore-study-after.json).
В новом рендере возврат прежнего направления снизил вызовы 1491 → 978,
p95 6,7–6,9 → около 6,0 мс. Окончательная реализация сохраняет направление;
цвет/облачность/интенсивность света улучшены. Сценарий получил отдельный
диагностический флаг после основного замера; обычная ветвь не менялась.

Скачки часов компенсируют нужды контрольного персонажа/часы существ; это
проверка представления, не выживания в течение пропуска дней. `plant-feedback`
вызывает клиентский эффект напрямую; серверный сбор проверяется отдельным
игровым сценарием. Пользовательские профили не открывались.
[Профильный тест света](lighting-fixed-sun.log) прошёл после оптимизации.
