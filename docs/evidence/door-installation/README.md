## Результат

Дверь заменяет выбранный блок своей прямой стены или заполняет готовый
проём между двумя участками стены. Калитка аналогично заменяет свой забор.
Ось определяется стенами, R выбирает одну из двух сторон открывания.
Углы, пересечения и отдельная дверь без проёма запрещены. Сервер проверяет
направление, владельца, наличие материалов и занятость клетки.

Стоимость собственной стены засчитывается по обычной политике её разборки:
положительная разница списывается, отрицательная возвращается. Пол, крыша,
перекрытие и их свойства сохраняются. Демонтаж двери оставляет проём,
возвращает стоимость двери и не восстанавливает старую стену. Повторная
установка в этот проём не дублирует материалы.

Генератор таверн определяет ось тем же `BuildRules.door_facing` после
размещения и зеркального отражения клеток. Исправлен и поворот открытой
створки по востоку/западу, чтобы он соответствовал выбранной стороне R.

## Съёмка

Нативный Godot 4.7.2, OpenGL/Compatibility, RX 580. Обычный LocalGame,
клиентские чанки и серверные запросы строительства, открытия и разборки.
Seed 431, single_continent, temperate, 12:00, ясная погода,
постоялый двор `inn@0,0,0`. NPC удалены только из отдельного проверочного мира
для стабильной съёмки. Обычные пользовательские миры не открывались.

«До» взято из предыдущего нативного прогона генератора 4: дверь была
закрыта, но весь блок стоял поперёк перегородки. «После» снято в новом мире
генератора 5 с тем же seed, зданием и ракурсом. Прежний оригинал 1800×1013,
новые — 1680×945. Для тройного сравнения новые кадры приведены к прежнему
размеру, выбран один и тот же прямоугольник и увеличен nearest-neighbour.
Содержимое кадров не ретушировалось. Полные оригиналы доступны отдельно.

В строительном примере сценарий находит свободную площадку внутри зала,
обычными запросами строит три собственных блока стены, заменяет средний
дверью и проверяет доплату в одну доску. Затем открывает дверь, разбирает её
и снова устанавливает в готовый проём с противоположной стороной открывания.
Все эти действия относятся только к отдельному проверочному миру.

## Сохранения

Изменение шаблонов повышает `Settlements.VERSION` с 4 до 5. Нужен новый мир.
Существующий проверочный мир предыдущего генератора был явно отвергнут;
SHA-256 его исходной базы до и после отказа совпал. Миграция не выполнялась.
Формат таблиц сохранения и схема сетевых сообщений не менялись.

## Повторение

Используйте новый отдельный профиль. Сценарий создаёт мир, удаляет его NPC
для съёмки и строит тестовую стену в зале. Для проверки отказа старого
генератора можно добавить `--old-world=/абсолютный/путь/к/старой/world.db`.

```sh
godot --path . --audio-driver Dummy \
  -s res://tools/experiment_3d/check_door_placement.gd -- \
  --out=/абсолютный/путь/к/кадрам \
  --profile=/абсолютный/путь/к/новому/отдельному/профилю --extras
```
