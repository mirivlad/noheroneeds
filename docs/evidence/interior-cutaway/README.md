## Исправление по замечанию автора

Предыдущий кадр «Окружение после выхода» был ошибочно принят за успешное
восстановление. Срез отключался, но уличный клиент не получал верхний этаж
постоялого двора: сервер отбирал его по необязательной метке `building_z`,
которой не было в сохранённых чанках. В базе при этом оставались 234 клетки
кровли и 67 стен. На изображении оставалось перекрытие первого этажа.

Сервер теперь определяет высоту по `Levels`. Сохранённые верхние чанки
постоялого двора загружаются для уличного вида без регенерации. Проверка выхода
требует реальной кровли и стен в данных клиента и в отрисованных модулях.
[Новая парная проверка](outside-roof-pair.webp) использует ту же уличную позу
и ракурс, что предыдущий неверный кадр. Исходный неверный снимок сохранён как
[outside-before-roof-fix.webp](outside-before-roof-fix.webp).

## Условия сравнения

Нативный Godot 4.7.2, Compatibility/OpenGL, AMD Radeon RX 580 2048SP,
дневное время 12:00, ясная погода. Настоящий LocalGame и клиентские чанки.
Отдельное сохранение: seed 431, single_continent, temperate, постоялый двор
`inn@0,0,0`, шаблон `base:roadside_inn`. Состояние игрока и камера в пяти
парных кадрах совпадают, что проверено сравнением `shots` в JSON.
Животные/жители удалены только из этого проверочного мира для стабильного
сравнения; мебель и планировка сгенерированы игрой. Пользовательские миры не
открывались. Время мира остановлено. Для фиксации позиций использовано
служебное перемещение; переходы между этажами выполнены через настоящую
лестницу. Это проверка визуализации, а не полный игровой сеанс.

Исходный код до изменения — коммит `afe2825`, SHA-256 адаптера
`1eb5f26c6dc0629768936374da017c731d5fbc020ca53d11672a5e2526082d3d`.
Точные позы, адаптер GPU, исходные хеши сценариев и результаты —
[before.json](before.json), [after.json](after.json). Сценарий после дополнен
непарными проверками силуэта и выхода; пять парных поз не изменены.
Хеши изображений и сравнение поз — [comparison.json](comparison.json).

## Повторение

```sh
godot --path . --audio-driver Dummy \
  -s res://tools/experiment_3d/check_interior_cutaway.gd -- \
  --out=/абсолютный/путь/к/кадрам \
  --profile=/абсолютный/путь/к/отдельному/профилю --extras
```

Для сравнения до/после нужно использовать один и тот же отдельный профиль.
`--extras` добавляет кадр за перегородкой и проверку выхода. Сценарий меняет
состояние своего мира и удаляет его NPC: не указывайте профиль обычной игры.
