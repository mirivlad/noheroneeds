## Поведение

На текущем этаже остаются интерьер, полные дальние стены и перегородки;
срезаются две наружные стороны по камере и верх своего дома. Улица и
соседние здания с крышами остаются видимыми. Нижние этажи сохраняют наружную
геометрию, а пол текущего этажа закрывает их помещения. Мебель и обитатели
закрытых нижних комнат не передаются; их карта не исследуется. Силуэт
показывает только собственного персонажа за препятствием. Указатель не
выбирает уличное существо сквозь сохранённый пол. После выхода возвращается
целый дом с настоящей крышей. Серверные высоты и правила движения не меняются.

## Условия

Нативный Godot 4.7.2, OpenGL/Compatibility, RX 580, LocalGame и обычные
клиентские чанки. Seed 431, single_continent, temperate, 12:00, ясная погода,
постоялый двор `inn@0,0,0`. Сохранение скопировано из отдельного проверочного
профиля предыдущего этапа. NPC удалены только из проверочного мира для
стабильного сравнения; обычные пользовательские миры не открывались.

Входы и переходы между этажами выполнены через настоящие лестницы;
позиции для съёмки выставлены служебным перемещением. После пяти парных кадров
и кадра выхода сценарий добавляет в эту копию мира третий этаж через `Levels`
и сохранённые клетки, а затем поднимается туда через настоящую лестницу.
Это контролируемый трёхэтажный пример, а не изменение генератора таверн.
Текущий этаж находится на `z=2`, нижние — на `z=1` и поверхности. Основной
двухэтажный проверочный профиль при этом не меняется.

Во время съёмки отключены пользовательский ввод и обычный `_process` игры;
сценарий сам продвигает LocalGame и отрисовку. Камера фиксируется перед кадром.
Полный список поз и исходных хешей: [before.json](before.json),
[after.json](after.json). Совпадение пяти парных поз проверено автоматически.

## Повторение

Скопируйте исходный двухэтажный проверочный профиль в **новый отдельный
каталог**. Сценарий добавляет третий этаж после парных кадров; готовая
трёхэтажная копия повторно не используется как исходная.

```sh
godot --path . --audio-driver Dummy \
  -s res://tools/experiment_3d/check_floor_stack.gd -- \
  --out=/абсолютный/путь/к/кадрам \
  --profile=/абсолютный/путь/к/новой/копии/профиля --extras
```

Коммит и push не выполнены. Результат оставлен для визуального одобрения автора.
