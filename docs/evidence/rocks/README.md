# Скалы: сравнение этапа 2

Godot 4.7.2, GL Compatibility, Radeon RX 580 2048SP, seed 431, малая умеренная
планета. До — `main` на `829a3cb`; после — кандидат этапа 2. Реальные игровые
кадры из LocalGame; окно и растр 960×540, полдень, ясная погода, ветер отключён.

Материальная площадка использует настоящие серверные `base:rock` и только
для снимка меняет материальный атрибут вершин по четырём колонкам. В природных
сценах действует обычный выбор материала по пространственному полю.
Белые полосы между скалами присутствуют на исходном кадре: это существующий
грунт/снег, а не созданные новой геометрией отверстия.

[Проход на границе чанков после работы киркой](after/mined-edge.png).
[Нативный журнал](after/native.log): 13 проверок без провалов. Обычный курсор,
серверная добыча и движение через открывшуюся клетку работают.
[Копия старого мира](saved-world.json): 10 проверок без провалов, в том числе
приоритет сохранённого прохода при повторном открытии. [Журнал](saved-world.log).

Замер рендера находится в `render_benchmark` каждой сцены: 120 кадров прогрева,
360 измерений, без VSync/ограничителя FPS и параллельных тестов. Камера и
симуляция остановлены. Это проверка статичной отрисовки, не всей игры или GPU
таймеров. Максимальное изменение p95 — +4,9%; исходные числа и ограничения —
[ROCKS_REPORT](../../ROCKS_REPORT.md).
