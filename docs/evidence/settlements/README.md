# Игровые снимки поселений

Откройте [галерею](index.html). Это нативные кадры Godot 4.7.2, а не коллажи.
Три сохранённых мира: площадь (hot/11), перекрёстки (cold/7), изгиб
(temperate/431). Они различаются климатом и сетью улиц; стартовая специализация
во всех трёх — равнинная деревня. Береговая и горная сети проверяются отдельно
регрессионными тестами, этими снимками они не представлены.

В каждом каталоге `capture.json` содержит параметры настоящего сохранённого
мира, здания, SHA-256 исходников и контрольные суммы выбранных изображений.
WebP сжат без потерь: декодированные RGB-пиксели сверены с исходными PNG.
Базы миров, профили и временные журналы сюда не включены.

Команды воспроизведения из корня проекта (нужно графическое окружение):

```sh
godot --path . --audio-driver Dummy -s res://tools/experiment_3d/check_settlements.gd -- --out=/tmp/nhn-hot-11 --seed=11 --climate=hot --count=2
godot --path . --audio-driver Dummy -s res://tools/experiment_3d/check_settlements.gd -- --out=/tmp/nhn-cold-7 --seed=7 --climate=cold --count=2
godot --path . --audio-driver Dummy -s res://tools/experiment_3d/check_settlements.gd -- --out=/tmp/nhn-temperate-431 --seed=431 --climate=temperate --count=2
```

Съёмка ждёт полной загрузки области и сборки геометрии, проверяет подъём и
спуск по настоящей лестнице. Внутри используется штатный срез стен и крыши.
Обоз для кадра управляемо установлен на действительную стоянку: он состоит
из серверных торговца, телеги и лошади и входит в состояние торговли.
Самостоятельное движение двух обозов проверено отдельным интеграционным тестом;
изображение стоянки не выдаётся за доказательство случайного прибытия.

Галерея — локальный материал проверки. Публичный дизайн вики не меняется,
её опубликованная версия остаётся привязана к игровому релизу.
