# Растительность: исходный main и кандидат

База `356c7e4`, ветка кандидата `codex/natural-world-vegetation`.
Настоящий LocalGame, серверные чанки и RO-персонаж; Godot 4.7.2,
GL Compatibility, Radeon RX 580 2048SP. Seed 431, полдень, ясная погода.
Сценарий — `tools/experiment_3d/check_vegetation.gd`. Пользовательские миры не открывались.

Луг — обычная сгенерированная местность. Ботаническая площадка специально
заполнена настоящими ID `cover` **только в одноразовом мире проверки**:
слева направо высокая трава, клевер, камыш, рогоз, пшеница, морковь,
обычный куст, ягодник, сухой куст. Это не новая генерация или добавленные ресурсы.

Камеры и игровое время одинаковы. Оконный менеджер изменил запрошенные размеры:
исходный растр 1680×945, кандидат 1800×1013. Снимки сохранены без ресайза.
Это визуальное сравнение, а не попиксельный эталон или контролируемый замер
производительности. Положение свободно движущихся NPC/зверей не фиксировалось.
Шум исходного грунта и насыщенная палитра земли относятся к следующему этапу,
здесь они не перерабатывались. Для неподвижных кадров ветер кандидата отключён.

Итоговый сценарий завершился с **15 проверками, без провалов**:
[метаданные](gameplay/capture.json), [журнал](gameplay/native.log).
Сценарий учитывает масштаб физических пикселей относительно логического курсора
и выбирает пустой быстрый слот через обычное обновление HUD, синхронизируя руки
клиента и сервера. [Параметры сравнения](comparison.json).
