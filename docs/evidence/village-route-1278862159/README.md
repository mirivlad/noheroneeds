# Пустой маршрут на северо-восток — 12.11.2026

Проверено последнее локальное сохранение «Новый мир», seed `1278862159`:
план планеты format 3, small, temperate; surface generator 18, settlements 5.
SQLite открыт только для чтения. Игровое сохранение и генератор не изменялись.

Открыты 240 поверхностных чанков в пределах x=-2…23, y=-24…2. Персонаж около
(693,-675) клеток. Стартовая деревня имеет центр (60,60), границы (-1,26,143,53).
В районах (1,0), (0,-1), (1,-1), по которым проходит открытый коридор, деревень
действительно нет. Это не ошибка отображения карты. Оранжевые треугольники
рисуются `MapPainter` для спусков/входов в подземелья.

Воспроизведение размещения по **сохранённому** глобальному плану с теми же
колбэками SurfaceGenerator:

| Район | Проверенные планировки | Результат |
|---|---|---|
| (0,0) | 39 с водой под участками, 6 у стартовой зоны, 1 допустимая | Только стартовая деревня |
| (1,0) | 29 с водой под участками | Ни одной |
| (0,-1) | 38 с водой под участками, 7 с водой под общественной площадкой | Ни одной |
| (1,-1) | Вероятность 0.970227 при cluster_chance=0.75 | Район пропущен |

Это сочетание озёрного рельефа, строгой проверки сухих участков и короткого
случайного поиска. Гарантируется поиск стартовой деревни, но не наполнение
каждого подходящего района и не встреча деревень вдоль выбранного направления.
Для больших деревенских планировок такой поиск может давать чрезмерные пустоты.

Диагностический подкласс **только в build/** с 128 попытками вместо 16 находит
дополнительную допустимую деревню (-220,-478) в районе (0,-1). В остальных трёх
районах результат тот же. Это подтверждает, что в северном районе существует
сухое место, пропущенное текущим поиском; это не обещание исправить всю плотность
одним увеличением числа попыток. Новая точка лежит западнее открытого коридора.

Исправление требует отдельной задачи с регрессией этого seed и проверки
плотности на разных планетах. Нельзя автоматически менять уже сохранённые
чанки или подставлять деревни в посещённые места. В текущем изменении животных
генерация остаётся прежней.

Существующий `test_villages_are_met_often` проверяет SurfaceGenerator без
сохранённого WorldPlan. Его успех не покрывает этот озёрный план. Для исправления
нужна отдельная регрессия именно планетарного мира, а не только старой географии.
