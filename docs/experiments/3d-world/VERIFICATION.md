## Что проверяет сквозной сценарий

Настоящий локальный сервер и GameClient, ходьба, персонаж LPC, выбрасывание и подбор
предмета, сгенерированный житель и разговор, ray picking дерева при повернутой камере,
ЛКМ и рубка до пня, перестроение принятого чанка, мышиный чертёж и постройка двери,
picking/открытие двери, настоящий пещерный вход на −1, picking/добыча природной породы,
исчезновение её экземпляра из MultiMesh, обычное строительство шахты на −2, оба
обратных перехода и отсутствие добытой породы после закрытия и повторного открытия БД.

Для воспроизводимости сквозной тест использует отдельный мир с seed 431; генерация
мира и все изменения выполняются прежними средствами игры. Пользовательский launcher
открывает собственный постоянный экспериментальный мир.

## Производительность обычного игрового цикла

Отдельный запуск после завершения тестов, без параллельной проверки: 900 кадров,
персонаж в настоящей деревне, 25 чанков, 7825 объектов, 14 спрайтов персонажей/животных.
VSync включён. Последние окна по 300 кадров показали **60,0 и 59,6 FPS**.
В последнем окне наибольший `delta` — 41,9 мс. В существующей симуляции существ
зарегистрирован отдельный тик 47,4 мс. Это короткий локальный замер, не гарантия
минимальной частоты кадров при любом исследовании мира.

Дополнительно launcher из `main` запускался с движением `--walk=1,0` на 600 кадров:
25 чанков, 7935–8045 объектов, первое окно 47,6 FPS (загрузка, пик 149,7 мс),
следующее — 60,0 FPS. Проверка не меняла ветку основной копии.

При публикации отдельно проверены SHA-256 всех 93 исходных Git blobs. Для байтов
сторонних лицензий задано исключение из нормализации CRLF в `.gitattributes`
только экспериментальной ветки. В проверку анимации также включено непрерывное
проигрывание ходьбы NPC между сетевыми snapshot.

[Полный журнал обычного запуска](evidence/steady-3d.log). Начальная генерация/загрузка
ресурсов и переходы между локациями могут давать более длинные задержки; это явно
не объявляется стабильными 60 FPS во всех условиях.
