# Жизнь зверей — проверка 0.12.0, 25.10.2026

Этап 11 разрешён автором. Проверка Windows-клиента через интернет отложена
автором до настоящего подключения; этот отчёт не закрывает сетевой сбой.

## Поведение и сохранения

`test_animal_life` — 12 сценариев с `ServerWorld`, настоящими существами,
местностью, боем и SQLite: живая пара, отсутствие замены убитых после
перезапуска, ёмкость растительности и общий корм разных видов, местный мороз,
переселение той же особи, преграды, возраст и продукция, голод после выгрузки,
поимка и насыщение, защищённый скот, память последнего увиденного положения,
летопись потерь, старые строки и ошибки контента.

Дополнительно: возраст и голод проходят через `GameServer` к клиенту;
`WorldView` держит маленький размер между кадрами и увеличивает ту же куклу
при взрослении. Молоко нельзя получить у телёнка или некормленой коровы;
клиент объясняет обе причины.

Первый полный прогон: **387 тестов, 0 ошибок, 489,1 с**. После оптимизации
индекса видов: **387 тестов, 0 ошибок, 476,1 с**. Две ошибки ENet ожидаемы
в отрицательных сценариях; предупреждений об утечках нет. Для того же кода
`cccc55c` [CI также прошёл](https://github.com/mirivlad/noheroneeds/actions/runs/40150826952):
387 тестов, 0 ошибок, 197,0 с.

## Нагрузка

Команда: `tools/run_tests.sh --bench --only=bench_snapshots --test=500 --snap_ticks=400`.
20 клиентов и 500 дополнительных существ, один процесс, без запущенной
графической игры; та же сцена и бюджет раздумий, 400 измеренных тиков.

| Вариант | Тики 1–200: p50 / p99 / max, мс | Тики 201–400: p50 / p99 / max, мс |
|---|---|---|
| Перебор всех соседних существ | 60,5 / 78,0 / 197,4 | 56,9 / 67,2 / 68,1 |
| Индекс по видам | 30,9 / 54,0 / 174,8 | 27,7 / 41,9 / 46,1 |

Время раздела `creatures` за вторые 200 тиков: 7813,3 → 2065,2 мс.
В начале замера остаётся отдельный длинный тик; нельзя утверждать, что
абсолютно все тики укладываются в 50 мс. Это проверка текущей локальной
нагрузки, не замер интернет-соединения и не гарантия для любого сервера.

## Собранная игра

Запущен экспортированный Linux-бинарник 0.12.0 с обычным `App` и локальным
авторитетным сервером. Изолированный профиль и подготовленные сохранения:
пары овец, коров и кур дали приплод через обычную логику животноводства;
другая сцена показывает возраст после 120 игровых часов. Миры подготовлены
вне репозитория и не затрагивают игровые сохранения пользователя.

- Xvfb 1920×1080, OpenGL Compatibility; снимки настоящего окна через X11.
  Это программный рендер, не проверка аппаратного GPU или Windows.
- Движение животных и обычные анимации сохраняются; на время наведения для
  одного снимка процесс кратко приостанавливался, затем продолжил работу.
- [Детёныши рядом со взрослыми](young.png): ягнёнок, телёнок, цыплёнок.
- [Взрослые животные](grown.png): отдельное сохранение с теми же видами после
  срока роста, не искусственно увеличенный снимок предыдущей сцены.
- [Осмотр голодной овцы](hungry-inspect.png): «Овца (ваша) · голодает».
- Обычный запуск ещё одного сохранения: голодный волк и домашняя овца,
  без действий игрока. [До охоты](hunt-before.png), [после поимки](hunt-after.png).
  Чтение сохранённой базы подтвердило гибель овцы, новое время еды у волка
  и шерсть без мяса на земле — [результат](hunt-result.json). Позже волк
  напал и на человека по прежним правилам территории; сытость останавливает
  охоту на животных, а не территориальную агрессию к игроку.

Windows portable ZIP и установщик EXE собираются из одного каталога экспорта.
Локальная сборка четырёх пакетов завершилась успешно; `SHA256SUMS`, проверка
ZIP и версия deb прошли. SHA-256 извлечённого из установщика EXE совпадает
с экспортом: `f8c929e10dcba7bc149bf2ada73a10c589cd67526f338d082cf35feedab500b7`.

и реальное внешнее подключение в этот этап не входят.
