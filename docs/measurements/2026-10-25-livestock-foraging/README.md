# Самостоятельное питание скота — поправка 0.12.1

Поправка автора: домашние животные едят сами, если еда доступна, предпочитая
корм игрока. Удалено прежнее ограничение 0.12.0 на обязательное кормление из рук.

## Проверки поведения

`test_animal_life`: 15 тестов, 0 ошибок. Дополнены сценарии самостоятельного
выпаса овец, коров и кур, в том числе детёнышей, сохранение новой даты еды,
недоступный корм за оградой, настоящий проход вокруг угла, расход одной вещи
из стопки, пустой загон и ограниченная ёмкость общего выпаса.

`test_husbandry`: 8 тестов, 0 ошибок. Проверены приоритет еды в руках хозяина
перед брошенным кормом и травой, самостоятельный поиск после отзыва предложения,
ручное кормление сразу после выпаса, молоко, яйца и приплод без ручного кормления.
Старые проверки голода теперь используют пустую землю, где нет доступной еды.

## Собранная игра

Экспортированный Linux-бинарник 0.12.1, обычный `App` и локальный авторитетный
сервер. Xvfb 1920×1080, OpenGL Compatibility с программным рендером. Это
проверка Linux-игры, не аппаратного GPU и не Windows. Отдельные тестовые профили
и подготовленные сохранения; игровые миры пользователя не затронуты.

1. На траве курица и овца сами обновили `ate_at`; `fed_at` осталось −1.
   Овца в пустом закрытом загоне оставалась голодной, хотя снаружи была трава.
   [Осмотр пустого загона](pasture-and-empty-pen.png) показывает «голодает».
2. В другом мире на пустой земле через обычный инвентарь брошена стопка
   из трёх единиц пшеницы (Shift + ПКМ). Голодная овца прошла от своего дома
   к месту, где игрок бросил корм, и съела одну единицу. [После еды](fed-from-drop.png)
   она вернулась к дому; на земле осталось две единицы. Сохранение подтверждает
   новую дату еды и отдельно время съеденного корма игрока.

[Данные из SQLite](runtime-result.json) прочитаны отдельным скриптом, без
изменения работающего игрового процесса. Вещи на земле живут до перезапуска
сервера по прежнему правилу ADR-0016; для второй проверки корм был брошен
после запуска игры, а не внесён в исходное сохранение.
