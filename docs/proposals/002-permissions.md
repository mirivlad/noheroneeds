# Предложение 002 — Права на чужое имущество (к ADR-0016)

**Статус:** на согласовании с автором. В коде пока ничего не меняется: ниже ревизия того, что есть, и предложение правил.

## 1. Что проверяется сейчас (ревизия 15.10.2026)

| Операция | Кто может сейчас | Проверка на сервере |
|---|---|---|
| Строить (`build`) | любой, где угодно (в досягаемости) | правила постройки (`BuildRules`), материалы |
| Перекрытие на чужих стенах, пристройка к чужому зданию | любой — здание сливается с чужим | нет проверки владельца |
| Строить на чужом этаже (на чужом перекрытии) | любой | нет проверки владельца |
| Разобрать (`dismantle`) | только владелец детали | `owner` |
| Открыть/закрыть дверь (`use`) | **любой** | нет проверки владельца |
| Сундук: заглянуть, положить, взять | только владелец | `owner` |
| Ударить по постройке (`strike_part`) | своё — всегда; чужое — если правило мира `break_others` | `owner`, правило |
| Ремонтировать | только владелец | `owner` |
| Добывать (руда, деревья) | любой | природное ничьё |
| Подобрать вещь с земли (`pickup`) | **любой**, в том числе вещи погибшего | нет |
| Подниматься по чужой лестнице, в чужой ход | любой | нет |
| Передать вещь (`transfer`) | любой — кому угодно | нет (это подарок) |
| Ударить персонажа | по правилу мира `pvp` | правило |

Неравномерности: двери открыты всем, а сундуки закрыты; к чужому дому можно пристроить перекрытие (и тем самым слить здания), а разобрать потом его нельзя никому, кроме владельцев отдельных деталей; вещи погибшего может забрать любой.

## 2. Предлагаемое устройство (одно для всех операций)

1. **Одна проверка на сервере:** `may(персонаж, действие, цель)`, вызываемая каждой операцией вместо разрозненных проверок `owner`. Действия — классы, а не названия операций:
   - `use` — пользоваться: двери, люки, лестницы, механизмы;
   - `store` — содержимое: сундуки, позже полки, бочки;
   - `build` — пристраивать к чужому: перекрытия на чужих стенах, детали на чужом этаже;
   - `dismantle` — разбирать;
   - `break` — ломать (осада, набег);
   - `repair` — чинить.
2. **Хозяин** — у каждой детали (уже есть `owner`), у здания — хозяин первого перекрытия (здание уже есть как сущность, ADR-0007).
3. **Доступ** задаёт хозяин: «только я», «мои друзья», «все». Отдельно для здания (по умолчанию для всех его деталей) и для отдельной детали (замок на одной двери, общий сундук в чужом доме).
4. **Друзья** — список персонажей у каждого персонажа (позже — поселения и гильдии как группы).
5. **Правила мира** задают значения по умолчанию и то, что можно в принципе (`pvp`, `break_others`, набеги NPC — уже решены в ADR-0016 как отдельные настройки).
6. **Клиент** узнаёт право от сервера (в описании детали), чтобы меню действий показывало недоступное с причиной, как сейчас с инструментами.

## 3. Предлагаемые правила по умолчанию — на решение автора

| Что | Предлагаю по умолчанию | Варианты |
|---|---|---|
| Двери | **открывает любой**, пока хозяин не поставил замок (деталь или свойство двери) | закрыты для чужих по умолчанию |
| Сундуки | **только хозяин** (как сейчас); хозяин может открыть друзьям или всем | — |
| Пристроить к чужому зданию (перекрытие на чужие стены, слияние зданий) | **только с правом `build`** у хозяина здания | как сейчас — любой |
| Строить на чужом этаже | **только с правом `build`** | — |
| Разобрать | только хозяин детали (как сейчас) и хозяин здания | — |
| Ломать чужое | только по правилу мира `break_others` / набеги (как сейчас) | — |
| Чинить чужое | **друзья хозяина** могут чинить | только хозяин |
| Вещи на земле | **любой** | вещи погибшего — только ему первые N минут (правило мира) |
| Природные ресурсы | любой | участки земли (если будут) |
| Чужие лестницы и ходы | любой | по правилу двери (замок) |

## 4. Вопросы автору

1. Двери по умолчанию открыты всем (и закрываются замком) или закрыты для чужих?
2. Нужна ли защита вещей погибшего на время и на сколько?
3. Нужны ли участки земли (право строить на «своей» земле) — или права только на постройки?
4. Друзья — личный список у каждого персонажа достаточен на первое время?
5. Может ли хозяин здания разбирать детали, поставленные в его здании другими (с его разрешения)?
