# Сайт и вики

Обязательны правила корневого `AGENTS.md` и `docs/WIKI_WORKFLOW.md`.
`site/content/guides/` — редакционные инструкции; каталог, обратные связи и поиск
создаёт `tools/site/build.py`. Не возвращайте ручную копию предметов и рецептов.
Текст о поведении сверяйте с игровым кодом, числа — с актуальным JSON.
Сохраняйте тёмное фэнтезийное оформление, золотые акценты, крупные настоящие
игровые кадры, поиск и узкую компоновку. Проверяйте результат в браузере.
В предпросмотре используется рабочий контент. Публикуется только результат
`tools/site/publish.py`, привязанный к последнему опубликованному релизу.

## Неприкосновенность визуального дизайна

Существующий дизайн сайта — часть требований, не временная заготовка.
При изменениях вики, генератора, путей GitHub Pages и CI **не переписывайте
HTML-разметку, CSS, шрифтовые подключения, палитру, изображения, макеты или
типографику**, если в задаче прямо не запрошен редизайн. Не удаляйте импорт
Manrope и Playfair Display из `site/assets/style.css`.
Если необходима точечная правка оформления, поясните её и сравните
скриншоты до/после на десктопе и мобильном экране.

Перед завершением убедитесь, что построенный Pages-артефакт содержит
`index.html` и `assets/style.css` на одном уровне относительно корня,
на всех страницах CSS возвращает HTTP 200, а вычисленные стили реально
содержат фирменный тёмный фон, золотые акценты и выбранные шрифтовые семейства.
Прохождение только функциональных тестов не доказывает сохранение дизайна.

## Главная страница — про игру, а не про разработку

`site/index.html` — витрина No Hero Needed для будущего игрока, а не
страница о репозитории, сборках, API, документации, генераторе или количестве
релизов. В первом экране показывайте игровой мир, реальные игровые изображения,
понятное описание того, что игрок может делать, и заметную кнопку скачивания
последнего опубликованного релиза. Энциклопедия, патчноуты и Github —
вспомогательная навигация, их нельзя ставить в центр главной страницы.
Сохраняйте фирменную визуальную стилистику и проверяйте её вместе с содержанием.
