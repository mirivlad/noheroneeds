# Сайт и вики

Обязательны правила корневого `AGENTS.md` и `docs/WIKI_WORKFLOW.md`.
`site/content/guides/` — редакционные инструкции; каталог, обратные связи и поиск
создаёт `tools/site/build.py`. Не возвращайте ручную копию предметов и рецептов.
Текст о поведении сверяйте с игровым кодом, числа — с актуальным JSON.
Сохраняйте тёмное фэнтезийное оформление, золотые акценты, крупные настоящие
игровые кадры, поиск и узкую компоновку. Проверяйте результат в браузере.
В предпросмотре используется рабочий контент. Публикуется только результат
`tools/site/publish.py`, привязанный к последнему опубликованному релизу.
