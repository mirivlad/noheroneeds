# No Hero Needed — официальный сайт и живая вики

Сайт интегрируется с текущей игровой веткой через отдельный PR. Генератор читает
игровые пакеты из `content/`, руководства — из `site/content/guides/`, патчноуты —
из `docs/changelog/`. Ручной копии предметов или рецептов больше нет.
Тёмная фэнтезийная тема, игровые кадры, карточки и мобильная навигация сохранены.

## Сборка и предпросмотр

Из корня репозитория:

```sh
python3 tools/site/build.py
python3 tools/site/serve.py
# http://127.0.0.1:18764/noheroneeds/
```

Сборка офлайн и детерминирована. Выходной каталог должен быть пустым либо
ранее созданным этим генератором: при пересборке устаревшие страницы удаляются. Другой игровой снимок можно указать через
`--game-root /путь/к/игре`, другой выходной каталог — `--out ПУТЬ`.
Свежий список опубликованных Releases:

```sh
python3 tools/site/sync_releases.py
python3 tools/site/build.py --published build/published-releases.json
```

Публикации проверяются через GitHub API; теги без Releases не считаются выпусками.
Скриншоты и лицензии копируются в сборку. Для её работы не нужны GitHub API,
Google Fonts, PHP, сервер приложений или база данных.

## Все проверки сайта одной командой

Первоначальная установка:

```sh
python3 -m pip install -r tools/site/requirements.txt
npm ci --prefix site
(cd site && npx playwright install chromium)
```

Затем: `tools/site/test.sh`. Команда запускает генерацию/барьер, Python-тесты,
проверку JavaScript и Playwright под настоящим подпутём `/noheroneeds/`.
Игровой регрессионный набор отдельно: `tools/run_tests.sh`.

## Правила изменений и публикация

Смотрите обязательный [процесс документации](../docs/WIKI_WORKFLOW.md), корневой
[AGENTS.md](../AGENTS.md) и карту `mechanics-manifest.json`.

`release.yml` блокирует упаковку и GitHub Release при неготовых патчноутах,
каталоге, руководствах, ссылках или тестах — и для тега, и для ручного запуска.
Публичная вики собирается из **последнего опубликованного тега**, включая
закреплённый снимок документации, а не из будущей игры в `main`.
Предпросмотр рабочей ветки не является публичной версией.

Нужная настройка владельца: **Settings → Pages → Source → GitHub Actions**.
В окружении **github-pages → Deployment branches and tags** также разрешите
**Branch: main** и **Tag: v*.*.***; сейчас разрешена только старая ветка сайта.
Слияние PR требует разрешения автора. После него workflow **Published wiki**
публикует сайт в корне `https://mirivlad.github.io/noheroneeds/`, без `/site/`.
До успешной проверки deploy новая публикация не заявляется как готовая.
