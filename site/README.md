# No Hero Needed — сайт проекта и игровая вики

Исходники сайта находятся в директории `site/` ветки `feat/game-site-wiki` репозитория `mirivlad/noheroneeds`. Основная ветка `main` не изменена.

## Открыть локально

```sh
cd site
python3 -m http.server 8080
# http://127.0.0.1:8080/
```

Это статический сайт: главная, игровые руководства, справочник, история релизов.

- `index.html` — главная.
- `wiki.html` — интерактивная энциклопедия с поиском, рецептурными связями и обучением у NPC.
- `guides.html` — руководство по игровым механикам.
- `updates.html` — список из 18 опубликованных релизов (от 0.1.0 до 0.16.0).
- `data/wiki.json` — 70 игровых предметов, 41 рецепт, 5 профессий и навыки из базового контента.
- `data/releases.json` — патчноуты с ссылками на GitHub.
- `CODEX_PROMPT.md` — подробное задание на дальнейшую автоматизацию вики, генерацию и обновление патчноутов.

## Проверка

```sh
python3 -m unittest discover -s site/tests -v
node --check site/assets/site.js
```

В ветке предусмотрен workflow `Website checks`.

## Развёртывание

Сайт пригоден для GitHub Pages: путь к сайту должен быть каталогом `site/` в сборке Actions, либо содержимое `site/` нужно скопировать в корень ветки `gh-pages`. GitHub Pages сам по себе не публикует произвольный каталог `site/` через режим `Deploy from a branch`.

**Статус:** сайт и первичный снимок данных загружены; Pages и автоматическая генерация из игрового контента ещё не включены. Доработку генераторов и CI проверки новых игровых механик поручить Codex по `CODEX_PROMPT.md`.

Скриншоты и иконка загружаются из публичного репозитория GitHub; внешние шрифты необязательны.
